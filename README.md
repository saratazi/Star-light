# 🌌 Stellar Photometry with Python
### Measuring Star Brightness using Astropy and NASA Data

This project uses Python to process and visualize astronomical data stored in **FITS (Flexible Image Transport System)** files. The goal is to perform aperture photometry—measuring the light intensity of celestial objects.

## 🚀 Features
* **FITS Data Handling:** Opening and inspecting professional telescope data.
* **Logarithmic Scaling:** Using `simple_norm` to reveal dim nebulae without washing out bright stars.
* **Visualization:** Custom colormaps (Magma/Viridis) for better scientific analysis.
* **Remote Data Fetching:** Automatically pulls real NASA sample data for testing.
📚 Libraries Used

Astropy - Core astronomy library.

Photutils - Tool for star detection (photometry).

Matplotlib - For generating scientific plots.
